## 📥 تحميل وتثبيت نسخة لينكس (Linux Desktop)

يمكنك تحميل النسخة الجاهزة مباشرة من صفحة [**Releases**](https://github.com/AshrafCode519/sakeenah/releases) أو من أحدث عملية بناء في [**GitHub Actions**](https://github.com/AshrafCode519/sakeenah/actions).

### 1. تثبيت حزمة دبيان / أوبونتو (`.deb`):
مناسب لتوزيعات **Ubuntu**, **Debian**, **Linux Mint**, **Pop!_OS**:
```bash
sudo dpkg -i sakeenah_1.0.0_amd64.deb
# في حال نقص أي مكتبات:
sudo apt-get install -f
```
ستجد التطبيق مباشرة في قائمة البرامج باسم **"سَكِينة - Sakeenah"** مع الأيقونة الرسمية.

### 2. النسخة المحمولة الشاملة (`.tar.gz`):
تعمل على كافة توزيعات لينكس (Arch, Fedora, Manjaro, openSUSE) دون الحاجة لتثبيت:
```bash
tar -xzf sakeenah-linux-x64.tar.gz
./sakeenah
```

## ✨ المميزات الرئيسية

### 1. المصحف الشريف والتصفح النبوي (15 سطر مطابق للمدني)
- **تقسيم صفحات المصحف النبوي المدني بدقة:** 604 صفحة مقسمة إلى 15 سطراً متناسقاً تحاكي مصحف المدينة المنورة.
- **نمطان للعرض:**
  - **عرض المصحف الحقيقي (Mushaf View):** مع إطارات ذهبية وزخارف رأس السور والبسملة.
  - **عرض البطاقات التفاعلي (Card View):** بطاقات قراءة مريحة مع أزرار تشغيل التلاوة الصوتية ونسخ الآية.
- **فهرس متكامل لـ 114 سورة:** تصنيف مكي ومدني، عدد الآيات، رقم صفحة البداية، وبحث فوري سريع.
- **المختصر في التفسير:** نافذة تفسير منبثقة بمجرد النقر على أي آية.
- **التلاوات الصوتية:** استماع فوري لأصوات كبار القراء مع تظليل الآية المقروءة.
- **صانع بطاقات الآيات والتدبر:** تحويل أي آية وتفسيرها إلى بطاقة دعوية مصممة بأربعة أنماط لونية فاخرة (الزمرد، الليل، المخطوطة الورقية، والذهب النوراني) للمشاركة.

### 2. حصن المسلم والظهور الذكي (بروح "أذكار المسلم")
- **أذكار مقسمة:** أذكار الصباح، أذكار المساء، أذكار بعد الصلاة، أذكار النوم والاستيقاظ.
- **عداد تفاعلي ذكي:** ينبض عند النقر مع اهتزاز تفاعلي (Haptic feedback) وبيان فضل كل ذكر وسنده الصحيح.
- **شريط الأذكار الطافي:** ظهور تلقائي لأذكار دورية خفيفة على الشاشة قابلة للنسخ والتبديل دون مقاطعة العمل.

### 3. السبحة الرقمية الذكية (Smart Masbaha)
- قرص تسبيح مركزي نابض مع إطار إسلامي ذهبي.
- قائمة أذكار سريعة ومختارة + إمكانية كتابة ذكر مخصص.
- خيارات لتحديد الهدف (٣٣، ٩٩، ١٠٠، أو حر مفتوح).
- عداد للدورات المكتملة وإحصائيات تسبيح اليوم والمجموع الإجمالي.

### 4. حلقات الأوراد ومواقيت الصلاة
- **حلقات الورد اليومي (Daily Rings):** 4 دوائر تفاعلية لحساب نسبة الإنجاز اليومي للعبادات (أذكار الصباح، أذكار المساء، ورد القرآن، هدف التسبيح).
- **مواقيت الصلاة والقبلة:** حساب دقيق لمواقيت الصلوات الخمس والشروق مع تنبيه الصلاة القادمة وبوصلة اتجاه الكعبة المشرفة.

## 🎨 الهوية والتصميم الإسلامي
- **الألوان:** الأخضر الزمردي الملكي (`#0F382C`)، الذهب الخالص (`#D4AF37`)، وخلفيات الورق العتيق (`#F9F6F0`).
- **الوضع الليلي:** أسود هادئ مع أخضر داكن يحمي العين أثناء القراءة ليلاً.
- **الزخارف:** رسام متجهي هندسي (`CustomPainter`) للنجمة الثمانية الإسلامية ونقوش الأرابيسك وأقواس المحراب.

## 🚀 طريقة البناء والتشغيل المحلي

### المتطلبات:
- تثبيت [Flutter SDK](https://flutter.dev) (الإصدار المستقر Stable).

### التشغيل والمعاينة على المتصفح (Web):
```bash
flutter run -d chrome
```

### التشغيل على سطح المكتب (Linux):
```bash
flutter run -d linux
```

### التشغيل على سطح المكتب (Windows):
```bash
flutter run -d windows
```

### بناء حزمة لينكس `.deb` محلياً:
```bash
chmod +x scripts/build_linux_deb.sh
./scripts/build_linux_deb.sh
```
